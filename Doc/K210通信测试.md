# K210通信测试

## 公共端口语义

上层代码只使用以下语义宏，不直接使用具体硬件UART编号：

```c
UART_PORT_K210
UART_PORT_E220
DEBUG_UART_PORT
```

MSPM0G3519工程中，K210使用UART1，E220使用UART4，调试日志使用UART0和板载CH340。

## 公共测试入口

- `Test_K210_DigitCommUpdate`：多数字快照测试。
- `Test_K210_RoadCommUpdate`：道路状态和事件测试。
- `Test_K210_VisionCommUpdate`：通用视觉测试预留入口。
- `Test_K210_RoadProfileUpdate`：道路参数档位发送测试。
- `Test_K210_SingleDigitCommUpdate`：旧版单数字固定帧测试。

这些入口统一由`User/Test/test.h`声明。运行任一K210测试时，任务表必须先注册：

```c
{ AppTask_BSP_Background, 1U, 0U },
{ K210_Comm_Update,       5U, 0U },
```

道路档位测试还必须注册`Key_Update`。专项测试结束后恢复正式任务表；本文件不规定当前正在使用的任务组合。
## 道路档位测试按键

`Test_K210_RoadProfileUpdate`使用以下按键：

- KEY1：PB0，核心板A08，选择`K210_ROAD_PROFILE_CURRENT`；
- KEY2：PB1，核心板A09，选择`K210_ROAD_PROFILE_OLD`；
- KEY3：PB13，核心板B10，当前仅输出BRIGHT未启用提示；
- KEY4：PA8，核心板B12，当前仅输出DARK未启用提示。

四个外接按键均使用内部上拉，按下时将GPIO连接到GND。任务表必须先注册`Key_Update`和`K210_Comm_Update`。
