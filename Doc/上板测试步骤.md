# MSPM0G3519 上板测试步骤

测试应按以下阶段依次进行。前一阶段未通过时，不进入可能带来更大电流或机械运动
的下一阶段。

## 阶段 1：静态检查

1. 对照[参数和引脚说明](参数和引脚说明.md)检查所有线序。
2. 用万用表确认 3V3 与 GND 不短路。
3. 确认外部 ICM20948 使用 3.3 V 逻辑。
4. 断开电机主电源并悬空车轮。
5. 确认 SWDIO、SWCLK、NRST 和 GND 可可靠连接。

通过标准：无短路、无 5 V 信号直接进入 MCU、调试器能识别目标。

## 阶段 2：下载与基础运行

1. 下载 Debug 固件。
2. 检查程序能进入 `main` 和调度循环。
3. 观察 SysTick 是否按 1 ms 递增。
4. 测试 LED1、LED2、RGB，以及 KEY1=PB0/A08、KEY2=PB1/A09、KEY3=PB13/B10、KEY4=PA8/B12、KEY5=PB31/USER。
5. 连续运行数分钟，观察是否复位或进入异常处理。


外接KEY1～KEY4均应一端接GPIO、另一端接GND，不需要外接上拉电阻。未接按键时内部上拉会保持未按下状态。通过标准：时基稳定，按键响应正常，程序无异常复位。

## 阶段 3：通信接口

1. 分别测试 K210 UART 和 E220 UART 的发送、接收与连续数据。
2. 扫描或读取 I2C0 设备，确认地址和应答。
3. 测试显示初始化、填屏和连续刷新。
4. 在连续显示刷新时同时运行 I2C 读取，检查 DMA 是否都能完成。

通过标准：UART 无持续丢包，I2C 无 NACK/超时，显示无花屏或卡死，四个 DMA
通道无冲突。

## 阶段 4：外部 ICM20948

1. 按指定 SPI1 引脚连接外部 ICM20948。
2. 读取 WHO_AM_I，确认芯片通信。
3. 静止放置，检查加速度、角速度数据是否稳定。
4. 逐轴转动车体，确认 X/Y/Z 方向。
5. 检查 PB21 数据就绪中断是否持续触发。
6. 完成陀螺仪零偏和姿态初始标定。

通过标准：身份寄存器正确，无持续 SPI 错误；静止值合理，三轴方向与软件约定一致。

## 阶段 5：低风险传感器与执行器

1. 测试灰度 4051 的八路顺序、黑白响应和阈值。
2. 测试 VL53L1X、HX711、激光和蜂鸣器。
3. 舵机脱离机械负载或留足空间，从中位开始小范围动作。
4. 标定舵机中位、最小和最大安全脉宽。

通过标准：传感器读数符合物理变化，舵机不抖动、不堵转、不碰撞机构。

## 阶段 6：编码器

1. 保持电机断电，手动正向转动每个车轮。
2. 检查对应编码器计数是否只影响目标轮。
3. 记录正向计数符号，必要时修正方向宏。
4. 核对每圈计数及轮径参数。
5. 特别检查后轮 GPIO 软件 QEI 在较高转速下是否漏计数。

通过标准：四轮通道对应正确，正负方向一致，每圈计数误差在可接受范围内。

## 阶段 7：电机开环

1. 车轮悬空并准备断电。
2. 单路电机从很小 PWM 开始测试。
3. 确认方向引脚、PWM 通道和编码器反馈一一对应。
4. 依次测试四路，不要首次同时启动。
5. 检查电源压降、驱动温升和 MCU 是否受干扰复位。

通过标准：四路方向正确，调速连续，无异常发热和复位。

## 阶段 8：闭环与整车

1. 先单轮验证速度闭环，再验证四轮。
2. 低速标定速度环、姿态和转向参数。
3. 架空验证急停、失联和传感器异常处理。
4. 落地进行短距离直行与低速转向。
5. 最后启用循迹、路线任务及 K210 联动。

通过标准：闭环稳定，无持续振荡；失联和异常状态能安全停机；路线功能按预期执行。

## 建议记录

每个阶段记录固件版本、接线照片、通过项、失败现象和最终参数。所有标为“待确认”
的硬件结论，应在验证后同步更新到本目录文档和 `Migration` 记录中。
