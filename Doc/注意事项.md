# MSPM0G3519 工程注意事项

## 1. 硬件范围

当前目标只有 MSPM0G3519 核心板，不应假设 EVM 扩展板上的屏幕、按键、LED、
Flash、EEPROM、无线模块或 IMU 存在。所有小车外设都应按
[参数和引脚说明](参数和引脚说明.md)单独接线。

惯性传感器必须使用外部 ICM20948，接到 SPI1 和 PB21 中断脚。不要把代码或
接线切换到核心板宣传图中的板载 ICM45686。

## 2. 上电安全

- 初次上电先断开电机主电源，只给核心板和低功耗传感器供电。
- 电机电源和逻辑电源应按驱动板要求连接，并保证逻辑地共地。
- 确认所有模块输出不会向 MSPM0G3519 输入 5 V。
- 调试 PWM 前将车轮悬空，并从小占空比开始。
- 舵机应使用满足峰值电流的独立电源，避免核心板复位。

## 3. SysConfig 与生成文件

外设实例、引脚或 DMA 通道变更时，应先修改：

```text
User/Config/empty_mspm0g3519.syscfg
```

随后重新生成 `ti_msp_dl_config.c` 和 `ti_msp_dl_config.h`，并确认生成内容已经
同步到 `User/Config`。不要只手工修改生成文件，否则下一次生成会覆盖修改。

当前 DMA 固定分配为 SPI0 TX/RX 通道 0/1、I2C0 TX/RX 通道 2/3。添加新的 DMA
外设前必须先重新检查通道冲突。

## 4. 异步接口缓冲区

- SPI 异步传输开始后，调用方提供的发送和接收缓冲区必须保持有效，直到回调完成。
- I2C 异步发送数据会复制到 BSP 内部 32 字节缓存；超过限制的请求会失败。
- I2C 异步接收缓冲区由调用方提供，回调前不得释放或复用。
- 回调在 BSP 周期任务中执行，不应包含长时间阻塞、死循环或大延时。
- 所有异步传输均有超时保护；超时后应检查接线、从设备地址和中断状态。

## 5. 中断共享

PB21 的 ICM20948 中断与后轮软件 QEI 共用 GPIOB 中断入口。修改 GPIO 中断代码
时必须保留基于挂起位的分别派发，不能在入口中无条件只处理某一种设备。

UART 使用接收中断和环形缓冲区。若出现丢包，应先检查波特率、接地、线序和任务
读取周期，再调整缓冲区大小。

## 6. 方向与标定

以下项目无法仅通过编译确认：

- 四路电机的正转方向。
- 四路编码器计数正负方向及每圈脉冲数。
- ICM20948 在车体上的 X/Y/Z 安装方向和零偏。
- 灰度传感器通道排列、阈值与环境光影响。
- 舵机中位、左右极限和机械干涉。
- 路线参数、速度环及转向环参数。

这些参数必须在低速、可急停的条件下逐项标定，不能直接按原 STM32 参数高速运行。

## 7. 文档边界

`Doc/Legacy_STM32` 中的 Markdown 是原项目历史资料，只用于理解算法和功能来源。
其中的 STM32 GPIO 名称、HAL 调用、DMA、定时器和中断配置均不适用于本工程。
当前接线和操作应以 `Doc` 根目录文档及 `Migration` 记录为准。
## 8. E220 无线串口

E220使用UART4：PB10发送、PB11接收、PB28读取AUX。透明传输模式下M0和M1必须可靠拉低。

E220专项测试必须注册`AppTask_BSP_Background`，因为UART发送、E220延迟队列和显示驱动都由该后台任务推进。测试函数已经直接刷新LCD和OLED，不要同时注册其他LCD或OLED页面任务。

MSPM0芯片标识通过`BSP_GetDeviceIdHash()`读取Factory Region生成。禁止在TI工程中使用STM32F407的`0x1FFF7A10` UID地址。
