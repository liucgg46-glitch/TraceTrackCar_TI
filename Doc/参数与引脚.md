## 2. ICM20948模块接线

本工程使用 ICM20948 的 SPI 模式。下表优先使用模块上实际印刷的名称，并在斜杠后补充 SPI 标准名称。

| ICM20948模块丝印 | SPI中的作用 | MSPM0G3519连接 |
| --- | --- | --- |
| `VCC` | 模块电源 | `3.3V` |
| `GND` | 电源地 | `GND` |
| `SCL / SCLK` | SPI时钟 | `PB16` |
| `SDA / MOSI / SDI` | 主控发送、模块接收 | `PB15` |
| `AD0 / MISO / SDO` | 模块发送、主控接收 | `PB14` |
| `NCS / CS` | SPI片选，低电平有效 | `PB12` |
| `INT` | 数据就绪或事件中断 | `PB21` |
| `EDA` | 模块辅助I2C数据线 | 不接 |
| `ECL` | 模块辅助I2C时钟线 | 不接 |
| `FSYNC` | 外部同步输入 | 不接 |

你当前模块上看起来像 `ADO`、`NT` 的丝印，接线时分别按 `AD0`、`INT` 对照。

不要按 I2C 接法把模块的 `SCL`、`SDA`接到 PA1、PA0。本工程中它们处于 SPI 模式：

```text
模块 SCL/SCLK  → PB16
模块 SDA/MOSI  → PB15
模块 AD0/MISO  → PB14
模块 NCS/CS    → PB12
模块 INT       → PB21
```
