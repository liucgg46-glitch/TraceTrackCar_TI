# MSPM0G3519 参数与引脚

## 1. 系统参数

| 项目 | 当前配置 |
| --- | --- |
| 主控 | MSPM0G3519 |
| 系统时钟 | 32 MHz |
| 软件时基 | SysTick 1 ms |
| UART | 115200，8N1 |
| I2C0 | 400 kHz |
| ICM20948 SPI1 | 4 MHz |
| 显示 SPI0 | 8 MHz |
| 电机 PWM | 20 kHz |
| 舵机 PWM | 50 Hz |
| 调试接口 | SWD：PA19/PA20 |

## 2. 核心板资源

| 功能 | 引脚 |
| --- | --- |
| LED1 / LED2 / RGB | PA14 / PA17 / PA29 |
| KEY1 | PB0，核心板 A08 |
| KEY2 | PB1，核心板 A09 |
| KEY3 | PB13，核心板 B10 |
| KEY4 | PA8，核心板 B12 |
| KEY5 / 板载 USER | PB31 |
| 蜂鸣器 | PA15 |

KEY1～KEY4 使用内部上拉，一端接 GPIO，另一端接 GND。

## 3. 通信和总线

| 设备 | 接口 | 引脚 |
| --- | --- | --- |
| Type-C / CH340 调试 | UART0 | PA10 TX，PA11 RX |
| K210 | UART1 | PB4 TX，PB5 RX |
| E220 | UART4 | PB10 TX，PB11 RX，PB28 AUX |
| OLED、VL53L1X、灰度 MCU | I2C0 | PA0 SDA，PA1 SCL |
| 外接 ICM20948 | SPI1 | PB16 SCLK，PB15 MOSI，PB14 MISO，PB12 CS，PB21 INT |
| TFT LCD | SPI0 | PB3 SCLK，PB2 MOSI，PC9 CS，PC8 DC，PB23 RESET，PA30 BL |

SPI0 显示为只发送模式，不使用 MISO；PA10 用于 UART0 调试发送。

## 4. 电机和编码器

### 电机

| 位置 | PWM | 方向 1 | 方向 2 |
| --- | --- | --- | --- |
| 左前 FL | PC2 / TIMA0 CCP0 | PB6 | PB7 |
| 右前 FR | PC4 / TIMA0 CCP1 | PB8 | PB9 |
| 左后 RL | PC0 / TIMA0 CCP2 | PB20 | PB24 |
| 右后 RR | PA28 / TIMA0 CCP3 | PB25 | PB27 |

### 编码器

| 位置 | A 相 | B 相 | 实现 |
| --- | --- | --- | --- |
| 左前 FL | PA26 | PA27 | TIMG8 QEI |
| 右前 FR | PB29 | PB30 | TIMG9 QEI |
| 左后 RL | PB17 | PB18 | GPIO 软件 QEI |
| 右后 RR | PB19 | PB22 | GPIO 软件 QEI |

后轮使用 GPIO 软件解码，4WD 下必须实测最高可靠计数速度。

## 5. 其他外设

| 功能 | 引脚 |
| --- | --- |
| 4051 模拟输出 | PA25 / ADC 通道 2 |
| 4051 选择线 | PA24、PA31、PC1 |
| 舵机 1 / 2 | PA12 / PA13 |
| 激光 | PC6 |
| HX711 SCK / DOUT | PC7 / PA7 |
| E220 AUX | PB28 |
| ICM20948 INT | PB21 |

本工程只使用外接 ICM20948，不假设扩展板上存在板载 IMU。

## 6. DMA

| 通道 | 用途 |
| --- | --- |
| DMA0 | SPI0 TX |
| DMA1 | SPI0 RX 配置保留 |
| DMA2 | I2C0 TX |
| DMA3 | I2C0 RX |

UART 使用中断和软件环形缓冲区；ICM20948 短帧 SPI 当前不占 DMA。

## 7. 参数位置

| 参数类型 | 文件 |
| --- | --- |
| 2WD/4WD、E220 模式 | `User/BSP/vehicle_config.h` |
| 底盘、循迹和动作 | `User/Algorithm/control_config.h` |
| 编码器映射、反向和滤波 | `User/Driver/drv_encoder.h` |
| 灰度来源 | `User/Driver/drv_gray_sensor.h` |
| 姿态与航向 | `User/Algorithm/attitude_estimator.h` |
| 路线选择 | `User/Route/route_config.h` |
| 整车状态机选择 | `User/APP/task_profile_config.h` |

引脚变化先改 SysConfig。
