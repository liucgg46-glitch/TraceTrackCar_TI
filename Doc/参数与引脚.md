# MSPM0G3519迁移工程参数与引脚

## 1. 系统与通信

| 项目 | 当前配置 |
| --- | --- |
| 主控 | MSPM0G3519 |
| 软件时基 | SysTick 1 ms |
| 调试串口 | UART0：PA10 TX、PA11 RX，115200 8N1 |
| K210 | UART1：PB4 TX、PB5 RX，115200 8N1 |
| E220 | UART4：PB10 TX、PB11 RX，PB28 AUX |
| I2C | I2C0：PA0 SDA、PA1 SCL，400 kHz |
| ICM20948 | SPI1：PB16 SCLK、PB15 MOSI、PB14 MISO、PB12 CS、PB21 INT |
| LCD | SPI0：PB3 SCLK、PB2 MOSI、PC9 CS、PC8 DC、PB23 RESET、PA30 BL |

## 2. 按键

| 按键 | 引脚 |
| --- | --- |
| KEY1 | PB0 / A08 |
| KEY2 | PB1 / A09 |
| KEY3 | PB13 / B10 |
| KEY4 | PA8 / B12 |
| KEY5 | PB31 / USER |

## 3. 电机和编码器

| 位置 | PWM | 方向脚 | 编码器 |
| --- | --- | --- | --- |
| FL | PC2 / TIMA0 CCP0 | PB6、PB7 | PA26、PA27 / TIMG8 |
| FR | PC4 / TIMA0 CCP1 | PB8、PB9 | PB29、PB30 / TIMG9 |
| RL | PC0 / TIMA0 CCP2 | PB20、PB24 | PB17、PB18 / GPIO QEI |
| RR | PA28 / TIMA0 CCP3 | PB25、PB27 | PB19、PB22 / GPIO QEI |

## 4. 其他外设

| 功能 | 引脚 |
| --- | --- |
| 4051 | PA25，PA24、PA31、PC1 |
| HX711 | PA7 DOUT、PC7 SCK |
| 舵机 | PA12、PA13 |
| 蜂鸣器 | PA15 |
| SWD | PA19、PA20 |
