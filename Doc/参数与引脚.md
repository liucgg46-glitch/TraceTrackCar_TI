## 2. ICM20948模块接线

TI工程代码中的`SPI_BUS2`是第二条逻辑SPI总线，实际映射到MSPM0G3519硬件SPI1，
并不表示应照搬STM32的SPI2引脚。

| ICM20948模块丝印 | SPI标准含义 | MSPM0G3519连接 |
| --- | --- | --- |
| `VCC` | 模块电源 | `3.3V`（仍须以模块规格为准） |
| `GND` | 电源地 | `GND` |
| `SCL / SCLK` | SPI串行时钟 | `PB16 / SPI1_SCLK` |
| `SDA / SDI / MOSI` | 模块串行数据输入 | `PB15 / SPI1_PICO` |
| `AD0 / SDO / MISO` | 模块串行数据输出 | `PB14 / SPI1_POCI` |
| `NCS / CS` | 软件片选，低电平有效 | `PA9` |
| `INT` | 中断输出 | `PB21` |
| `EDA / AUX_DA` | 辅助I2C数据线 | 不接 |
| `ECL / AUX_CL` | 辅助I2C时钟线 | 不接 |
| `FSYNC` | 外部帧同步输入 | 未使用时接`GND` |

```text
模块 VCC       → 3.3V
模块 GND       → GND
模块 SCL/SCLK  → PB16
模块 SDA/SDI   → PB15    （MSPM0端：MOSI/PICO）
模块 AD0/SDO   → PB14    （MSPM0端：MISO/POCI）
模块 NCS/CS    → PA9
模块 INT       → PB21
模块 EDA       → 不接
模块 ECL       → 不接
模块 FSYNC     → GND
```

NCS不能永久接地。PA9在每次SPI事务开始时拉低，事务完成后拉高。

`WHO_AM_I=0xEA`只确认ICM20948主芯片身份。默认
`DRV_ICM20948_MAG_REQUIRED=0U`：封装内AK09916磁力计初始化失败时保留六轴采样，
并以`mag_valid=0`标记磁场数据不可用。

感为灰度模块手册规定工作电压为5V，SDA/SCL端口默认浮空，由主机提供上拉。
3.3V主控应将I2C上拉到3.3V；不要安装会把SDA/SCL上拉到5V的板载应急跳线帽。
