# MSPM0G3519迁移工程工程说明

## 1. 工程目标

该工程用于非阻塞循迹小车，包含电机与编码器、底盘闭环、灰度循迹、动作库、路线状态机、ICM20948、VL53L1X、HX711、LCD/OLED、K210 和 E220。

## 2. 分层

| 层级 | 作用 |
| --- | --- |
| `User/Common` | 平台无关状态码和临界区抽象 |
| `User/BSP` | 芯片外设、引脚、中断、DMA、时基 |
| `User/Driver` | 器件驱动 |
| `User/Algorithm` | PID、循迹、姿态、里程 |
| `User/APP` | 底盘、动作、传感器管理、显示、整车任务 |
| `User/Route` | 路线规则和赛道实现 |
| `User/Test` | 专项测试入口 |

```text
APP / Route / Test
        ↓
Algorithm / Driver
        ↓
BSP
        ↓
MSPM0G3519
```

## 3. 启动流程

```text
BSP_InitAll()
→ Driver_Init()
→ App_Init()
→ Scheduler_Init()
→ Scheduler_Run()
```

## 4. 配置入口

| 配置 | 文件 |
| --- | --- |
| 静态任务表 | `User/APP/app_task_config.h` |
| 专项测试开关 | `User/Test/test_config.h` |
| 2WD/4WD 底盘模式 | `User/BSP/vehicle_config.h` |
| 控制参数 | `User/Algorithm/control_config.h` |
| 整车状态机 | `User/APP/task_profile_config.h` |
| 路线选择 | `User/Route/route_config.h` |
| 灰度来源 | `User/Driver/drv_gray_sensor.h` |

引脚、外设、时钟或 DMA 改动时先修改 `User/Config/empty_mspm0g3519.syscfg`，再生成 `ti_msp_dl_config.c/.h`并 Rebuild。

## 5. 周期建议

- 1 ms：后台和传感器状态机；
- 5 ms：K210 解析；
- 10 ms：按键、编码器、底盘、动作、循迹；
- 20 ms：显示任务；
- 200～500 ms：日志。

## 6. I2C组合事务

`BSP_I2C_MasterWriteRead_DMA_Async()`用于“写命令后立即读取”的组合事务。
写阶段不发送STOP；MSPM0控制器产生TX_DONE后，`BSP_I2C_Task()`等待控制器进入
IDLE且保持BUSBSY，再发出读阶段的重复START。不能在TX_DONE中断内立即启动读阶段，
否则部分器件会只收到写命令，总线停在IDLE/BUSBSY，直到软件超时复位。

感为8路灰度模块的ping必须使用上述组合事务：写`0xAA`、重复START、读回`0x66`。
地址扫描只验证从机是否应答地址，扫描到`0x4C`不等于ping和模拟量读取已经正常。

## 7. ICM20948降级行为

ICM20948主芯片和封装内AK09916磁力计分别判定。`WHO_AM_I=0xEA`表示主芯片SPI读链路
与器件身份正常，但不代表AK09916辅助I2C已经完成初始化。

当`DRV_ICM20948_MAG_REQUIRED=0U`时，AK09916初始化或内部辅助I2C失败不会再令主芯片
进入离线重试；驱动继续完成陀螺仪零偏标定并提供加速度、角速度和温度，
`mag_valid`保持0。需要磁力计作为强制条件时，将该宏设为`1U`。
