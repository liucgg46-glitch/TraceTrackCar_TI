# MSPM0G3519 测试任务

## 1. 启用

1. 将 `User/Test/test_config.h` 中的 `PROJECT_TEST_TASKS_ENABLE`设为`1U`。
2. 在 Keil 中确认需要的测试源文件参与 Target 编译。
3. 在 `User/APP/app_task_config.h` 临时包含 `test.h`并替换任务表。
4. 测试完成后恢复正式任务表和测试开关。

基础任务：

```c
#define APP_SCHEDULER_TASK_LIST_DEFINE()                         \
Task_t task_list[] = {                                           \
    { AppDiagnostics_HeartbeatUpdate, 10U, 0U },                 \
    { AppTask_BSP_Background,     1U, 0U },                      \
};                                                               \
const uint8_t TASK_NUM =                                         \
    (uint8_t)(sizeof(task_list) / sizeof(task_list[0]))
```

`AppDiagnostics_HeartbeatUpdate()`使用 PA14 作为运行指示。`Test_GPIO_Toggle()`只是普通 GPIO 翻转测试。

`AppTask_BSP_Background()`必须保留，它推进 UART、E220 队列、LCD SPI、OLED I2C 和其他异步状态机。

## 2. 常用组合

### 五按键

```c
    { Key_Update,      10U, 0U }, \
    { Test_Key_Update, 10U, 0U }, \
```

KEY1～KEY4 为 PB0、PB1、PB13、PA8；KEY5 为 PB31。

### E220 双向通信

```c
    { Test_E220_Link_Update, 10U, 0U }, \
```

该测试直接刷新 LCD/OLED，不要同时注册其他显示页面。

### K210 单数字

```c
    { K210_Comm_Update,                 5U, 0U }, \
    { Test_K210_SingleDigitCommUpdate, 10U, 0U }, \
```

道路档位测试还需要 `Key_Update()`。

### 姿态

```c
    { Sensor_Update,        1U, 0U }, \
    { Test_Attitude_Update, 10U, 0U }, \
```

### 底盘和动作

常见前置任务：

```c
    { Key_Update,      10U, 0U }, \
    { Encoder_Update,  10U, 0U }, \
    { Motion_Update,   10U, 0U }, \
    { Chassis_Update,  10U, 0U }, \
```
