# MSPM0G3519迁移工程上板与注意事项

## 1. 首次上电

1. 断开电机功率，只给主控和低功耗模块供电。
2. 检查3V3与GND是否短路。
3. 主控、传感器、K210、E220、电机驱动逻辑地和USB转TTL共地。
4. 数字信号使用3.3 V逻辑。
5. 电机和舵机使用独立电源。

## 2. 调试串口接线

当前调试串口是UART3，不再使用板载UART0：

```text
PC6 / UART3_TX → USB转TTL RXD
PC7 / UART3_RX → USB转TTL TXD
GND            → USB转TTL GND
参数           → 115200、8N1
```

不要连接USB转TTL的5V输出。PC6、PC7已配置为UART3，不能再接激光使能或HX711数据线；对应信号已经迁移为`LASER_EN=PC3`、`HX711_DOUT=PC5`。

## 3. 推荐测试顺序

1. 下载和心跳；
2. GPIO、按键、灯、蜂鸣器；
3. UART3外接USB转TTL调试串口；
4. I2C、SPI、LCD/OLED；
5. K210、E220；
6. 灰度、ToF、HX711、ICM20948；
7. 编码器；
8. 电机开环；
9. 底盘闭环；
10. 动作、循迹、路线和整车状态机。

## 4. 安全规则

- 电机、底盘和动作首次测试必须悬空车轮；
- 同时只允许一个任务控制电机；
- `AppTask_BSP_Background()`不能删除；
- E220或显示专项测试时不要注册其他显示页面；
- 测试结束后恢复正式任务表和`PROJECT_TEST_TASKS_ENABLE=0U`。

## 5. SysConfig与中断

引脚复用必须修改`User/Config/empty_mspm0g3519.syscfg`并重新生成`ti_msp_dl_config.c/.h`，不能只手改生成文件。PB21 ICM20948中断与后轮软件QEI共用GPIOB中断入口；DMA0/1用于显示，DMA2/3用于I2C0。
