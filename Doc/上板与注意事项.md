# MSPM0G3519 上板与注意事项

## 1. 硬件范围

当前目标是 MSPM0G3519 核心板和外接小车模块，不假设 EVM 扩展板上的 LED、蜂鸣器、Flash、开关或 IMU 存在。ICM20948 使用外接模块。

## 2. 首次上电

- 先断开电机功率，只给核心板和低功耗模块供电。
- 所有模块逻辑地必须共地。
- MSPM0 GPIO 使用 3.3 V 逻辑。
- 上电前检查 3V3 与 GND 是否短路。
- 电机和舵机使用满足峰值电流的独立电源。
- 调试 PWM 时抬起车轮。

## 3. 推荐顺序

1. 编译、下载、PA14 心跳和 PB31 USER。
2. KEY1～KEY4、状态灯和蜂鸣器。
3. Type-C 调试串口。
4. K210 和 E220。
5. I2C、SPI、LCD/OLED。
6. ICM20948、VL53L1X、灰度和 HX711。
7. 单电机低占空比。
8. 编码器方向和每圈计数。
9. 底盘闭环、动作和循迹。
10. 路线和整车状态机。

## 4. SysConfig

```text
修改 empty_mspm0g3519.syscfg
→ 重新生成 ti_msp_dl_config.c/.h
→ 检查 Git 差异
→ Rebuild
```

不要只手工修改生成文件。

## 5. 中断和 DMA

- PB21 ICM20948 中断与后轮软件 QEI 共用 GPIOB 中断入口。
- DMA0/1 用于显示 SPI0，DMA2/3 用于 I2C0。
- UART 使用中断和环形缓冲区。
- 新增 DMA 外设前重新检查通道冲突。

## 6. 非阻塞规则

- `AppTask_BSP_Background()`必须持续运行。
- 异步 SPI/I2C 完成前，接收缓冲区不得释放或复用。
- 回调只置标志或保存少量数据。
- Driver 不得重复初始化 BSP 总线。
- 周期任务中禁止长延时和等待循环。

## 7. 显示和通信

- E220 测试已经直接刷新 LCD/OLED，不要同时注册其他显示页面。
- K210 测试必须保留 `K210_Comm_Update()`。
- E220 发送依赖 PB28 AUX。
- Type-C、K210 和 E220 使用三路独立 UART。

## 8. 2WD / 4WD

- 前轮使用 TIMG8/TIMG9 硬件 QEI。
- 后轮使用 GPIO 软件 QEI。
- 4WD 下实测后轮编码器最高可靠速度和 GPIOB 中断负载。

## 9. 标定

更换电机、轮胎、供电、编码器、灰度安装位置或任务周期后，重新确认电机方向、编码器方向和每圈计数、轮径轴距、灰度阈值、IMU 零偏以及舵机中位。

测试结束后恢复正式任务表和测试开关。
