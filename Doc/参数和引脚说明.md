# MSPM0G3519 参数和引脚说明

## 1. 系统参数

| 项目 | 当前配置 |
| --- | --- |
| 主控 | MSPM0G3519 |
| 系统时钟 | 32 MHz |
| 软件时基 | SysTick 1 ms |
| 调试接口 | SWD |
| UART 波特率 | 115200 bit/s |
| I2C0 速率 | 400 kbit/s |
| ICM20948 SPI | SPI1，4 MHz |
| 显示 SPI | SPI0，8 MHz |
| 电机 PWM | 20 kHz |
| 舵机 PWM | 50 Hz |

上述频率为当前软件配置。外设允许的最高频率、舵机脉宽范围和传感器稳定性须在
实板上再次确认。

## 3. 外部 ICM20948 接线

本工程只使用用户自己的外部 ICM20948 模块。

| ICM20948 模块 | MSPM0G3519 |
| --- | --- |
| VCC | 3V3 |
| GND | GND |
| SCLK | PB16 |
| MOSI / SDI | PB15 |
| MISO / SDO | PB14 |
| CS | PB12 |
| INT | PB21 |

模块必须工作在 3.3 V 逻辑电平。若模块同时引出了 AD0、FSYNC 等信号，本工程
暂未使用。中断输出极性与开漏设置需结合模块配置实测确认。

## 7. DMA 分配

| DMA 通道 | 用途 |
| --- | --- |
| 0 | 显示 SPI0 TX |
| 1 | 显示 SPI0 RX |
| 2 | I2C0 TX |
| 3 | I2C0 RX |

外部 ICM20948 的 SPI1 当前使用阻塞式短帧传输，不占用 DMA。UART 接收使用
中断和环形缓冲区。

## 8. 接线原则

- 所有数字信号以 3.3 V 逻辑为准。
- 核心板地、传感器地、电机驱动逻辑地必须共地。
- 电机电源不能直接由核心板 3.3 V 引脚供电。
- 高电流电机回路与传感器供电应做好退耦和布线隔离。
- 首次上电前用万用表检查 3V3 与 GND 是否短路。
