# MSPM0G3519迁移工程通信说明

## 1. 端口分工

| 用途 | 硬件和引脚 |
| --- | --- |
| 调试日志 | UART0：PA10 TX、PA11 RX，115200 8N1 |
| K210 | UART1：PB4 TX、PB5 RX，115200 8N1 |
| E220 | UART4：PB10 TX、PB11 RX，PB28 AUX |

上层统一使用 `DEBUG_UART_PORT`、`UART_PORT_K210`和 `UART_PORT_E220`。

## 2. E220 双向测试完整任务表

```c
#define APP_SCHEDULER_TASK_LIST_DEFINE()                         \
Task_t task_list[] = {                                           \
    { AppDiagnostics_HeartbeatUpdate, 10U, 0U }, /* 运行心跳 */         \
    { AppTask_BSP_Background, 1U, 0U }, /* UART、总线和异步驱动后台 */        \
    { Test_E220_Link_Update, 10U, 0U }, /* E220 双向通信 */             \
};                                                               \
const uint8_t TASK_NUM =                                         \
    (uint8_t)(sizeof(task_list) / sizeof(task_list[0]))
```

`User/BSP/vehicle_config.h`UART4 已固定用于 E220，PB10/PB11 接 E220，PB28 接 AUX。两台设备发送 `E220,本机ID,递增数字\r\n`，屏幕显示 SELF、TX、PEER、RX、接收计数和链路状态。

Type-C UART0 每 500 ms输出 aux、tx、rx、count、link、queue、defer、retry。

```c

    (uint8_t)(sizeof(task_list) / sizeof(task_list[0]))
```

K210 为 115200、8N1。多数字、道路状态和档位发送的完整任务表见《测试任务完整手册》。

## 4. UART 发送接口

- `BSP_UART_Write()`：日志流，可部分写入；
- `BSP_UART_WriteFrame()`：完整帧写入；
- `BSP_UART_WriteFrameNow()`：Driver 重试队列使用。
## UART4 固定 E220 链路

TI 工程的三路串口已经固定分工：

- UART0：Type-C / CH340 调试；
- UART1：K210；
- UART4：E220，使用 PB10 TX、PB11 RX 和 PB28 AUX。

UART4 不再提供“普通直连 / E220”编译选择，E220 Driver 和双向通信测试始终编译。透明传输模式下，E220 的 M0、M1 仍需由硬件可靠拉低。
