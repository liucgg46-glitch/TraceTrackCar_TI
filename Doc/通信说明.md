# MSPM0G3519迁移工程通信说明

## 1. 端口分工

| 用途 | 硬件和引脚 |
| --- | --- |
| 调试日志、命令输入和回显 | UART3：PC6 TX、PC7 RX，115200 8N1，使用外接USB转TTL |
| K210 | UART1：PB4 TX、PB5 RX，115200 8N1 |
| E220 | UART4：PB10 TX、PB11 RX，PB28 AUX |

上层统一使用`DEBUG_UART_PORT`、`UART_PORT_K210`和`UART_PORT_E220`。`DEBUG_UART_PORT`仍等于`UART_PORT_DEBUG`，只是`UART_DEBUG`底层由UART0改为UART3，因此测试函数不需要逐个修改。

外接USB转TTL接线：

```text
PC6 / UART3_TX → USB转TTL RXD
PC7 / UART3_RX → USB转TTL TXD
GND            → USB转TTL GND
```

原板载UART0（PA10/PA11）不再作为本工程调试口使用。

## 2. E220 双向测试完整任务表

```c
#define APP_SCHEDULER_TASK_LIST_DEFINE()                         \
Task_t task_list[] = {                                           \
    { AppDiagnostics_HeartbeatUpdate, 10U, 0U }, /* 运行心跳 */         \
    { AppTask_BSP_Background, 1U, 0U }, /* UART、总线和异步驱动后台 */        \
    { Test_E220_Link_Update, 10U, 0U }, /* E220 双向通信 */             \
};                                                               \
const uint8_t TASK_NUM =                                         \
    (uint8_t)(sizeof(task_list) / sizeof(task_list[0]))
```

`User/BSP/vehicle_config.h`UART4已固定用于E220，PB10/PB11接E220，PB28接AUX。两台设备发送`E220,本机ID,递增数字\r\n`，屏幕显示SELF、TX、PEER、RX、接收计数和链路状态。

UART3外接USB转TTL调试串口每500 ms输出aux、tx、rx、count、link、queue、defer、retry。

K210为115200、8N1。多数字、道路状态和档位发送的完整任务表见《测试任务完整手册》。

## 4. UART 发送接口

- `BSP_UART_Write()`：日志流，可部分写入；
- `BSP_UART_WriteFrame()`：完整帧写入；
- `BSP_UART_WriteFrameNow()`：Driver重试队列使用。

## 5. 三路UART固定分工

- UART3：外接USB转TTL调试串口，PC6 TX、PC7 RX；
- UART1：K210，PB4 TX、PB5 RX；
- UART4：E220，PB10 TX、PB11 RX和PB28 AUX。

UART4不再提供“普通直连 / E220”编译选择，E220 Driver和双向通信测试始终编译。透明传输模式下，E220的M0、M1仍需由硬件可靠拉低。
