# MSPM0G3519 通信说明

## 1. 端口分工

```c
#define DEBUG_UART_PORT  UART_PORT_DEBUG
#define UART_PORT_K210   UART_PORT2
#define UART_PORT_E220   UART_PORT1
```

| 用途 | 硬件 | 引脚 |
| --- | --- | --- |
| Type-C / CH340 调试 | UART0 | PA10 TX，PA11 RX |
| K210 | UART1 | PB4 TX，PB5 RX |
| E220 | UART4 | PB10 TX，PB11 RX，PB28 AUX |

三路 UART 独立，调试日志不会混入 E220 数据。

## 2. E220

配置位于 `User/BSP/vehicle_config.h`。

```text
PB10 / UART4_TX → E220 RXD
PB11 / UART4_RX ← E220 TXD
PB28            ← E220 AUX
GND             ↔ E220 GND
```

M0、M1 必须可靠拉低。两端模块的信道、空中速率、地址和 UART 参数必须能够互通。

任务：

```c
{ AppTask_BSP_Background, 1U, 0U },
{ Test_E220_Link_Update, 10U, 0U },
```

测试帧：

```text
E220,SELF_ID,VALUE\r\n
```

本机 ID 由 `BSP_GetDeviceIdHash()`生成；ID 冲突时在 `User/Test/test_config.h` 设置不同的 `TEST_E220_SELF_ID_OVERRIDE`。

Type-C 日志重点观察 `aux`、`tx`、`rx`、`count`、`link` 和 `queue`。

## 3. K210

K210 使用 UART1、115200、8N1。协议层位于：

```text
User/APP/k210_comm.c
User/APP/k210_comm.h
```

支持单数字、多数字快照、道路状态、视觉快照和道路档位配置。解析任务：

```c
{ K210_Comm_Update, 5U, 0U },
```

上层只调用 `K210_Comm_*` 公共接口。

## 4. 调试串口

Type-C 调试使用 UART0。普通日志统一写入 `DEBUG_UART_PORT`，不得在 APP、Route 或 Test 中硬编码 UART0。

## 5. 完整帧发送

- `BSP_UART_Write()`：日志流，可部分写入。
- `BSP_UART_WriteFrame()`：完整帧写入，空间不足返回忙。
- `BSP_UART_WriteFrameNow()`：Driver 重试队列内部使用。
